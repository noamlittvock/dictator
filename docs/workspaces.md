# Workspaces

A routine opens your apps and tabs and puts the windows where you want them. Run it with a click, a keyboard shortcut, or “Workspace writing” in Commands mode.

## Save a layout

Use **Remember** to capture your current windows, or **Place apps** to choose an app, Mac, display and position yourself. Preview before running. Choose whether closed apps should open.

**Open tabs** adds pages in the browser and on the Mac you choose. Chrome-family browsers also support named profiles, so work and personal accounts can have different routines.

## Switch between routines

Turn on **Show only this routine's windows** to bring its windows forward and hide other apps. Running another group swaps them on the same desktop.

A routine can remember windows across your Macs. Each Mac opens and places its own apps. If one is unreachable, the others finish and Dictator names the missing Mac. A missing monitor sends windows to that Mac's main screen.

## Undo

Undo restores the positions from before the last run. It lasts until Dictator quits or another run replaces it. Newly opened apps stay open, and windows that can't be restored are reported.

Windows on another desktop are left alone. Switch to that desktop and run the routine there.
