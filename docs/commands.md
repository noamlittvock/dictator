# Commands

Turn on a command in **Commands**, hold **Right Option + Right Shift**, say the phrase and release. Change those keys in Settings › General.

| Say | Result |
|---|---|
| “Open Safari” | Open Safari. |
| “Code pantry fix the login bug” | Start Claude Code in your configured Pantry folder with that request. |
| “Workspace writing” | Run the saved writing routine. |
| “WhatsApp Dana I'll be late” | Open Dana's chat with the message filled in, using your configured People list. |
| “Shortcut start my workday” | Run that Apple Shortcut. |

Commands match your phrases and lists. A model doesn't choose which action to run. Turn a command off to stop matching it.

## Make your own

Choose **Build your own…**, enter what you'll say, then add actions. You can open apps and pages, type text, start a coding assistant, run a Terminal command or Apple Shortcut, call a webhook, or append to a file.

Add people or projects to **Your lists** so a phrase can pick one by name. Teach another pronunciation when a name is misheard. Limit a command to specific apps if the same phrase should do different things in different places.

Actions that send include a cancellation pause; press Esc to stop. WhatsApp can leave the message for you to send or send after the pause. Apple Shortcuts can opt into running right away. Review these choices before using a command.

## Other ways to run

Give a command a keyboard shortcut if it needs no spoken words. To launch it from another app, enable **Let other apps start this** and copy its `dictator://run` link. Commands that act ask for confirmation; links cannot supply spoken words.

## Share commands

Export selected commands and import the file on another setup. People's details and addresses are left out unless you include them. Review imported actions and fill missing values before turning them on; imports start disabled.

For file formats and URL behavior, see [Integrations](integrations.md).
