# Where Dictator is going

Reduce the distance between deciding what to do and getting it done. Reduce the attention needed to keep track of it afterward.

## Command now

Dictate, open a project, restore a workspace, run a saved action. Use a predictable command for a predictable job. Keep direct control whenever it helps.

This is what Dictator ships today: local dictation, configurable commands and window routines across your Macs.

## Supervise next

Starting work is half the job. See what's running, what's finished and what needs an answer. Return to a task with its context intact, without checking every terminal or rebuilding the situation in your head.

## Delegate later

Give an agent an outcome when the work needs reasoning. Inspect what it did, redirect it, or take over. Make permissions and limits visible, and make actions reversible where possible.

A person might delegate a presentation, adjust its layout by hand, run a command to replace an image, then ask an agent to review it. Moving between those modes should keep the work intact.

## What guides the design

- Use the simplest reliable way to do the job: direct manipulation, a saved command or an agent.
- Preserve context across apps, tasks and sessions.
- Ask for attention when a decision matters.
- Keep actions inspectable and authority with the person using the Mac.
- Keep personal data on the user's machines and make sharing deliberate.

Supervision and delegation are directions, not shipped features or dated commitments. The aim is a computer you can direct without having to watch it constantly.
